RSSrch is a Zotero plugin for managing RSS feeds with folders, filtering rules, relevance scoring, and research-focused discovery.

## Features

- Organize Zotero RSS feeds with folders

![[RSSrch - Folders Example.png]]

- Filter articles using customizable rules

![[RSSrch - Rule Manager Example.png]]

- Score papers based on research relevance

![[RSSrch - Rule Manager - Score.png]]

- Surface papers matching your research goals

![[RSSrch - Item List - Score Column Example.png]]

- Create AI-assisted research rules for your library

![[RSSrch - Menu - Export AI Rule Setup Package.png]]
## Installation

Download the latest plugin [release](https://github.com/SolveSaint/RSSrch-for-Zotero/releases/) and install it in Zotero 10.

**Installation with a large RSS library will take some time to process and enrich. Please be aware of this.**
